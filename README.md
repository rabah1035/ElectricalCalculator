# الحاسبة الكهربائية - Electrical Calculator

تطبيق سطح مكتب مكتوب بالـ **Python + PyQt6** لحساب أساسيات الهندسة الكهربائية، بواجهة ثلاثية اللغة (العربية / الفرنسية / الإنجليزية).

![Python](https://img.shields.io/badge/Python-3.11-blue) ![PyQt6](https://img.shields.io/badge/PyQt6-6.11-purple) ![اختياري: PyInstaller](https://img.shields.io/badge/PyInstaller-6.22-green)

## المزايا

- واجهة عربية كاملة (RTL) مع دعم الفرنسية والإنجليزية.
- زر **مساعدة** في كل شاشة يشرح الصيغة الحسابية والعناصر المراد إدخالها.
- تصميم داكن/فاتح متناسق وواضح.
- إمكانية التغليف إلى ملف تنفيذي واحد `ElectricalCalculator.exe` بدون الحاجة لتثبيت Python.

استخدم الحاسبة مباشرة من متصفحك بدون تثبيت أي شيء:

**🌐 https://rabah1035.github.io/ElectricalCalculator/**

نسخة الويب (مجلد `docs/`) مطابقة تماماً لمحرك الحساب في النسخة المكتبية، بكل الوحدات التسع والثلاث لغات.

## الوحدات الحسابية

1. **قانون أوم** — حساب الجهد / التيار / المقاومة.
2. **هبوط الجهد في الكابل** — أحادي وثلاثي الطور (معامل √3).
3. **شرط ك²س² (K²S²)** — السلامة الحرارية لموصل الحماية.
4. **مقاومة الـ LED** — حساب مقاومة التخفيض وقدرتها.
5. **حساب الجهد** — من القدرة والتيار (أحادي/ثلاثي الطور).
6. **حساب التيار** — من القدرة والجهد (أحادي/ثلاثي الطور).
7. **انزلاق المحرك** — السرعة المتزامنة والانزلاق وتردد العضو الدوار.
8. **مقطع الكابل** — حسب هبوط الجهد المسموح (نحاس/ألمنيوم).
9. **ألوان المقاومات** — قراءة القيمة من 4/5/6 حلقات حسب IEC 60062.

## التشغيل من المصدر

```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل التطبيق
python electrical_calculator.py
```

## التغليف إلى EXE

```bash
pyinstaller --onefile --windowed --noconfirm --name "ElectricalCalculator" electrical_calculator.py
```

النتيجة في مجلد `dist/ElectricalCalculator.exe` — ملف واحد يعمل على ويندوز بدون تثبيت Python.

## بنية المشروع

```
electrical_calculator.py    # الكود الكامل للتطبيق (واجهة + محرك الحساب + الترجمات)
ElectricalCalculator.spec   # ملف إعداد PyInstaller (يتجدد عند كل بناء)
requirements.txt            # المتطلبات
docs/                       # نسخة الويب (HTML/CSS/JS) المستضافة على GitHub Pages
```

## متطلبات النظام

- ويندوز 10/11 (للتغليف كـ EXE)
- بايثون 3.9+ (للعمل من المصدر)
- PyQt6 ≥ 6.5 (تلقائي عبر requirements.txt)

## التقنيات والمعايير

- المعايير الكهربائية المستخدمة: **IEC 60062** (أكواد الألوان)، معادلات الشبكة أحادية/ثلاثية الطور بمعامل **√3**.
- التصميم: PyQt6 مع QSS مخصص.
